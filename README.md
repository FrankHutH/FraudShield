# FraudShield
Aplicação única em [Projeto 2](Projeto%202/README.md), construída em Next.js e React, com jogos que consomem dados JSON por APIs GET do Next.js.

Para executar: `cd "Projeto 2" && npm install && npm run dev`.
Para validar: `cd "Projeto 2" && npm test && npm run build && npm run test:smoke`.
